# Guides

Starter pages for the reference material your group keeps for itself and others: what to do with old equipment, which computing to use, and how to work more efficiently. Unlike [records](../docs/records.md), which log what you have and what you've done, these pages are meant to be read, shared and published.

| Page | Helps with |
|---|---|
| [E-waste and unused equipment](e-waste.md) | `03-B` e-waste processing streams and policy |
| [Computing we use](compute.md) | `HPC1-B` computing infrastructure inventory |
| [Green computing tips](green-computing.md) | `HPC3-B` green computing best practices; also induction material for `G2-B` |

## Using them

1. Fill in each page: replace every **To fill in** note with your group's details, then delete the note. Search for `To fill in` to find what's left.
2. Publish them where your group already keeps documentation, such as your organisation's website or docs site. The pages are plain Markdown (MyST-compatible, so they work in a Sphinx site).
3. In each review, link the published page as evidence on the matching criterion's issue, and check it's still accurate. The page's history shows when it was last updated.

Keep these pages free of anything you wouldn't publish: no room numbers, asset tags or names of who has what. Those belong in records in a private repository.
